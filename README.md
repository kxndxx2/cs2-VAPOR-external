✨ Features
🔫 Weapon Logic
Aimbot: Highly configurable with FOV and Smoothness sliders.

Humanize: Adds natural movement to the aimbot to prevent detection.

Recoil Control: Automatically compensates for vertical and horizontal recoil patterns.

Triggerbot: Configurable delay and target selection.

Target Bone: Selectable hitboxes (Head, Neck, Chest, etc.).

👁️ Visuals (ESP)
ESP Master: Toggle all visuals on/off.

Bounding Box: 2D/3D box styles.

Skeleton: Draws player skeletons for precise tracking.

Health Bar: Displays enemy health values.

Team Filter: Distinct colors for teammates vs. enemies.

🏃 Movement
Bunny Hop (Bhop): Automates jumping to maintain velocity.

No Flash: Prevents screen whitening from flashbangs.

🛠️ Installation & Usage
Download the latest release from the Releases tab.

Extract the archive to a secure folder.

Launch Vapor.exe as Administrator.

Start Counter-Strike: Global Offensive.

Use the INSERT key to toggle the menu overlay.
